# Privacy policy for Stat Studio: Football Analytics

Effective date: 2026-09-26

Stat Studio: Football Analytics is an offline application. This policy explains what the application does with information entered by its users.

## Information stored on the device

The application can store team names, short codes, colours, venues, match dates, match statistics, notes, display preferences, and onboarding status in local application preferences. This information is entered by the user for football analysis. The application does not require an account, phone number, precise location, contacts, photos, or payment information.

## Sharing and collection

The application does not collect, sell, transmit, or share personal information. It has no analytics, advertising, crash reporting, authentication, cloud storage, or network service. No information leaves the device as part of normal use.

## Clipboard export and import

The user may choose to copy a versioned data export to the system clipboard or import a compatible export from the clipboard. The clipboard is controlled by the operating system and other applications may be able to read clipboard content according to device settings. Users should treat an export as containing the team and match information they entered.

## Retention and deletion

The user can delete all locally stored information from Settings using the reset action. Uninstalling the application also removes its local data according to device application storage rules.

## Children

The application is intended for an audience aged 18 and over and does not knowingly collect information from children.
